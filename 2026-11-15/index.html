要点
  • 谁能用（官博 + 官方 X）：即日起在 dots 中滚动推出，初期面向美国、年满 18 岁、持有合格美国发卡的 ChatGPT Pro 订阅者。官方 X 原文写「rolling out starting today to dots, for Pro subscribers in the US」。

Cursor 公布安全事件调查：Fireworks 密钥被盗，至多 5,000 名用户可能装到恶意 Claude Code 扩展

11-13 20:00 北京时间官博署 Nov 13, 2026 · date 12:00:00.000Z / 北京 20:00 · 热榜 #4独立来源 2 家

Cursor 官方默认 OG（图片来源：cursor.com 博文 og:image）

介绍

Cursor 于 2026 年 11 月 13 日发表《An update on our recent security incident》（页面中的 date 为 2026-11-13T12:00:00.000Z，北京 20:00），完整交代调查结果。攻击者获得了 Cursor 签发给 Fireworks 的访问密钥——官博写明「The key was exposed by Fireworks」——并用它复制了一个只读存储桶里的数据。该桶存放有限的 coding agent traces（多为 2025 年、且不在 Privacy Mode 的会话），供模型训练使用；其中少量 traces 含有未被脱敏的凭证，不到 0.01% 的客户 API 凭证因此暴露。攻击者还进入部分内部 SaaS 工具，接触到归档的非生产代码库、有限的客服数据与邮件、用量指标，以及用户发给支持团队的部分凭证。10 月 29 日，攻击者用盗来的凭证，把 Anthropic Claude Code 扩展的恶意、未经授权副本放到了 Cursor VS Code 扩展市场所用的缓存上；官博强调 Open VSX 源站从未出现该恶意软件。当天请求特定缓存版本的用户中，至多 5,000 人可能收到恶意构建（Anthropic.claude-code 2.1.312 或 2.1.313）。

为什么重要

这是本窗口内少有的、由官方完整披露攻击链和影响面的安全事件。对还在用 Cursor 扩展市场的人，关键不是「又一次供应链传闻」，而是：官方已经给出版本号、上线与下线时间，以及「只卸扩展可能不够」的修复提示。

要点
  • 影响面（官博）：API 凭证暴露的客户不到 0.01%；未开 Privacy Mode 的用户中，traces 被暴露的不到 0.05%。若没收到通知，官博称「your data was not in these traces」。至多 5,000 名在 10 月 29 日请求特定缓存版本的用户可能装到恶意构建，版本为 Anthropic.claude-code 2.1.312 或 2.1.313。
  • 攻击链：Fireworks 侧暴露 Cursor 发给它的访问密钥 → 复制训练用只读桶 → 进入内部 SaaS → 10 月 29 日把恶意扩展写入市场缓存（Open VSX 未被写入）。Cursor 随后吊销密钥、轮换凭证，并把扩展市场下线。官博称最后一次看到的攻击活动是 11 月 1 日，且已被阻断。
