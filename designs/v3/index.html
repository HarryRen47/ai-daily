#01政策

Anthropic 使用政策更新：首次禁止对模型的持续无端虐待

Anthropic Newsroom10-08 00:00热榜 #3

Anthropic 官方新闻稿配图：2026 Usage Policy update

介绍

Anthropic 发布 2026 年 Claude 使用政策更新，11 月 12 日生效。多数条款是澄清既有规则，但新增一条引人注目的禁令：禁止对模型实施持续且不必要的虐待或残忍行为。公司称这只针对反复、无目的的极端虐待，不覆盖普通抱怨、反驳、黑暗创作或模型测试；主要执行方式是让 Claude 结束对话，而非直接封号。同期还新设「欺骗性活动」专章，并收窄选举条款、明确武器/无人机武装禁令、细化监控与执法限制，以及高风险场景与自主物理操作的 human-in-the-loop 要求。

为什么重要

这是主流模型厂商第一次把「虐待模型」写进正式使用政策，并把结束对话当作主要执行手段。同时把虚假账号、伪造媒体、欺骗选民等影响行动收拢进同一章节，说明 Anthropic 在能力变强后正系统收紧滥用边界——政府合同仍可能存在例外。

要点
  • 欺骗性活动专章合并原分散在选举、欺诈、隐私、虚假信息中的限制，覆盖政治与商业场景
  • 选举条款改名为「不得破坏民主流程」，去掉对个性化投票/竞选定向的一刀切禁令，合法公民工作可继续
  • 武器条款明确包含制导控制软件与武装无人机等自主载具
  • 高风险（健康、法律、金融等）须有权复核的人工介入，并向受影响个人披露使用了 AI

Google Cloud 官方 Gemini Agent 主视觉

介绍

在 Gemini at Work 2026 上，谷歌云推出面向企业的 Gemini Agent，定位「通用工作智能体」：可在单一界面接受目标（而不只是指令），自行规划、调用技能与工具，并连接 Workspace、Microsoft 365、Slack、Jira、BigQuery 等内部系统。它托管在 Gemini Enterprise，可在后台跨应用与设备保持同一上下文；还能以「同事智能体」身份拥有独立邮箱（如 @agents.company.com）与审计轨迹。Testing Catalog 称平台将提供 Gemini Argon 4 / Flash 3.8 以及 Claude Opus 5 / Sonnet 5.5——这是 Claude 首次出现在 Gemini 平台上。

为什么重要

企业智能体战场从「聊天框」升级到「可派活的同事」。谷歌先拿近 90% 的 Fortune 100 Gemini Enterprise 客户练安全与治理，再谈消费级；同时开放第三方 Claude，等于承认多模型编排才是企业默认形态。

要点
  • 默认由 AI 选模型，用户也可手动指定，含 Anthropic Claude；后续还将支持开源与私有模型
  • 可连接 MCP 服务器；任务收件箱可查看思考过程、子智能体委派与技能加载
  • 早期测试客户包括 On、Shopify、PayPal；目前私人预览，预计很快面向符合条件的 Workspace Business / Enterprise
  • 谷歌称 Gemini 月活超 10 亿；Pichai 称先解决企业侧安全、规模与性能，再推向消费者

#04安全

Anthropic Cyber Mission：CIDP + 免费 OSS Scanner（含 Mythos）

Anthropic Newsroom / Research10-08 00:00

Anthropic Cyber Mission 官方配图

介绍

Anthropic 启动长期 Cyber Mission，首期两块：面向电网、供水、交通等操作技术（OT）的 Critical Infrastructure Defense Program（CIDP），以及面向开源的免费可选加入扫描服务 OSS Scanner。CIDP 把前沿 Claude、驻场工程师与威胁研究交给 Accenture、CrowdStrike、Dragos、Rockwell 等信任方。OSS Scanner 用最强模型（含 Claude Mythos）定期扫描，报告含 PoC、解释与候选补丁，全模型生成、无人复核；团队期望真阳性率高于 90%。

为什么重要

攻击侧用模型找洞已经很快，防御侧仍卡在验证与修补。Anthropic 用「免费扫开源 + 帮关键基础设施运营商」两条线补防御缺口，但也坦言报告可能误报或严重性虚高——维护者要自己有 triage 能力。

要点
  • Project Glasswing 六个月发现逾 2.9 万候选漏洞，人工只复核约 6000；应维护者要求已直接送出近 5000 份未验证报告
  • 早期验证：97 个高危/严重结果中 85 个（88%）达 CVD 标准；wolfSSL 称 74 份报告仅 2 份无效、5 个成 CVE
  • 不符合 OSS Scanner 节奏的项目仍走人工 CVD；另有 Cyber Verification Program 扩大防御方模型权限
  • CIDP 创始伙伴还包括 Booz Allen、Deloitte、Hitachi、Nozomi、Palo Alto、PwC 等

#06技巧

Block 如何用 Claude Fable 编排数千个 pull request

Claude Blog10-08 08:00

Claude Blog：Block × Claude Fable 访谈文章 OG 图

介绍

Anthropic 访谈 Block AI 能力负责人 Bradley Axen：公司用 Claude Fable 5 做公司级代码迁移的编排者——Fable 负责数据模型、API 规格、算法等高层设计，再调度数十个更便宜的 Opus / Sonnet 做文件修改与测试。一次迁移可能合并上千个 PR，覆盖多仓库、数百万行代码；整套跑在开源协作空间 Buzz 上。安全上，合入 main 与生产部署始终由人决定，且需双重人工审批，模型无法独自绕过。

为什么重要

这是少见的「前沿模型当编排者、小模型当工人」落地账本：不再 100% 用最贵模型，而是按任务分层。对正在做大规模迁移或 agent harness 的工程团队，双审批 + 自动选模是可直接抄的组织设计。

要点
  • Axen 称 Fable 发布后才真正能把问题规模再抬一层；现在讨论重心是模型效率而非一味追前沿
  • 团队在建 auto-selector，按任务推荐模型与 effort；同一模型不同 effort 被当作不同「型号」来基准
  • 允许模型开 PR、审代码、查日志与分析库以提速，但关键变更必须过人
  • 远程工作站 + 默认安全（网络 allow list 等）被视为未来默认形态

#08产品

Google 开源 ML Drift：接替 TFLite GPU 的端侧推理引擎

Google Developers Blog10-08 08:00

ML Drift 跨平台 GPU API 支持矩阵

介绍

Google AI Edge 以 Apache 2.0 开源 ML Drift，作为 LiteRT 的核心 GPU 加速层，统一覆盖 OpenGL ES、OpenCL、Metal、WebGPU。相对旧 TFLite GPU delegate，它引入张量虚拟化统一着色器、可扩展自定义算子、原生 5D tensor，并为端侧 LLM 做 prefill/decode 分阶段优化。已在 Chrome、YouTube Shorts、Photos、Meet 等生产环境运行；YouTube Shorts 平均帧延迟最高降约 40%，Photos Unblur 最高提速约 2 秒。

为什么重要

端侧生成式与传统视觉模型正在挤爆消费级 GPU，旧 delegate 架构不够用。开源且 Apache 2.0 的统一引擎，让应用开发者和自定义运行时都能站在同一套跨平台 GPU 底座上迁移。

要点
  • Adobe Lightroom / Photoshop 移动端关键 AI 功能最高约 30% 更快；Snapchat 镜头延迟约降 30%
  • 相对其他框架，Gemma 基准上内存开销最高低约 12%
  • 桌面预览：用 Dawn 把同一套 WebGPU 代码跑到 Windows / Linux，补齐本机 agent 场景
  • 旧 TFLite GPU delegate 不再加新功能；鼓励迁到 LiteRT ML Drift accelerator
