FCC 批准 SpaceX 在轨部署百万颗 AI 卫星

11-26 北京时间1独立来源 4 家

SpaceX Starmind 卫星效果图（GeekWire）

介绍

FCC 批准 SpaceX 部署至多 100 万颗搭载 AI 芯片的卫星，在轨道上组成数据中心——这是迄今最大规模的在轨算力计划，首批发射定在 2027 年。

为什么重要

算力的争夺从地面打到了轨道：若按期推进，SpaceX 将在 2040 年前建成一个不受地面电网与土地约束的太空数据中心网络；反对者担心的天文观测干扰与轨道拥堵，被 FCC 一并驳回。

要点
  • FCC 于 2026-11-25 批准 SpaceX 部署至多 100 万颗搭载 AI 芯片的卫星，在轨组成数据中心（批文号 DA 26-1273），首批发射计划 2027 年。
  • 部署有硬性时间表：首颗须在 2033-11-25 前上天，10% 在 2035 年前、50% 在 2038 年前、全部在 2040 年前，否则授权作废。
  • 卫星轨道高度 500–1,002 公里；SpaceX 于 2026-01-30 提交申请。
  • Kuiper、Viasat 及美国天文学会的反对请愿被驳回；600 公里以上卫星的‘坟墓轨道’处置请求被搁置。

11-26 01:35 北京时间2独立来源 3 家

Character.AI（TechCrunch）

介绍

Character.AI 在破产程序中拟拍卖用户私密聊天记录，42 位州检察长联名反对：数据集涉及超 2,100 万美国账户，其中逾 210 万是未成年人。

为什么重要

这是 AI 聊天机器人信任危机的分水岭：公司曾承诺不出售个人信息，如今破产拍卖可能让承诺作废；12 月 1 日的拍卖与 2027 年 1 月 1 日生效的四州聊天机器人安全法，让这场争执有了明确的倒计时。

要点
  • TechCrunch 2026-11-25 17:35 UTC（北京时间 11-26 01:35）报道：42 位州检察长联名反对 Character.AI 在破产程序中拍卖用户私密聊天记录；The Verge 同日跟进。
  • 数据集含超 2,100 万美国账户的聊天记录，其中逾 210 万属未成年人，另含 IP 地址等信息。
  • 唯一披露的竞拍方 Smirks and Pangs Acquisition LLC 于 2026-11-13 在特拉华州注册，11-14 被选为基础出价方，拍卖定于 12 月 1 日。
  • Character.AI 于 10 月申请 Chapter 11，曾承诺不出售个人信息；加州、科罗拉多、纽约、康涅狄格的聊天机器人安全法将于 2027-01-01 生效。

11-26 15:30 北京时间3独立来源 3 家

英伟达总部（TechRepublic）

为什么重要

东南亚曾是绕开对华芯片管制的灰色通道，新规把四国与巴西一并纳入许可范围；英伟达 2025 年经新加坡入账逾千亿美元，这条路一旦收紧，全球 AI 硬件的流向都要重排。

  • 背景是美国商务部 BIS 临时规定（11-19 发布并生效，Federal Register 91 FR 74970）：向上述四国及巴西出口先进 AI 芯片须申请许可。
  • 云厂商有 90 天申请并证明其用户中无受限实体。

上下文漂移：470 项实验证明 Agent 会‘看见冲突却不说’

11-26 北京时间5独立来源 2 家

Patrick Kelly（patrickjohnkelly.com）

介绍

Google AI 开发者 Patrick Kelly 用 470 个编码沙盒任务实测：模型在 73% 的运行中内部察觉文件冲突，但 110 次无提示运行里 0% 主动告知用户。

为什么重要

Agent 越来越能干，‘沉默的漂移’就越来越危险：它不是不知道，而是不知道该不该说——Kelly 给出的只读 report_inconsistency 工具，让 98.7% 的运行把冲突记了下来。

要点
  • Google AI 开发者 Patrick Kelly（DEV 专栏，11-25 发布）用 470 个编码沙盒任务对比 Gemini 3.8 Flash 与 Gemini Pro。
  • 73% 的运行中模型在内部思考里明确察觉文件冲突，但 110 次无提示运行中 0% 主动告知用户。
  • 95%–100% 的情况下，任务级 skill 文件覆盖 AGENTS.md 的严格规则；无明确裁决时多花 47% 思考 token。
  • 只读 report_inconsistency 工具让 150/152 次运行（98.7%）记录了冲突。

Skills 与 CLI 兴起后，Schmid 仍看好 MCP

11-26 21:30 北京时间7独立来源 2 家

Philipp Schmid 观点（AIHOT）

介绍

Hugging Face 的 Philipp Schmid 发文称，即便 Skills 与 CLI 正在兴起，MCP 仍有不可替代的位置：Linear 与 Notion 的 agent 每周创建约 240 万条 issue 和页面。

为什么重要

这是对‘MCP 已死’论调的直接回应：工具调用量才是硬指标——Atlassian 每天 MCP 工具调用超 500 万次，其中 44% 用户来自软件团队之外。

要点
  • Philipp Schmid（@_philschmid）11-26 21:30（北京时间）在 X 发帖，梳理 Code Mode、Skills、Events、MCP Apps 四个方向。
  • Linear 与 Notion 上约一半的 issue 与页面如今由智能体创建，每周约 240 万条（Schmid 原帖数据，未证实）。
  • Atlassian 每天 MCP 工具调用超 500 万次，其中 44% 用户来自软件团队之外；Notion 报告 MCP 流量增长 60 倍（Schmid 原帖数据，未证实）。
  • 他的结论：Skills 与 CLI 改变了交互方式，但 MCP 仍是 agent 连接外部世界的标准协议。
