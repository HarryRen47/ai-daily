Weight-Space Programming：Astra 只改 0.016% 权重，MATH-500 7.9→48.1

11-03 01:51 北京时间周二维头条 · AIHOT 热榜 #1 · ~5.4 万赞独立来源 3 家

Weight-Space Programming 博文封面（来源：rikiyat.github.io）

介绍

北京时间 11-03 01:51（UTC 11-02 17:51，窗内），MIT CSAIL 博士生 @rikiyatakehi 等发博与原推：Weight-Space Programming——让前沿 LLM（GPT-6 Astra）原生读写神经网络权重。团队称 Astra 在 Python 内核里直接编辑 Qwen3.5-0.8B，只改 131,072 个权重（约 0.016%），无梯度/训练，MATH-500 7.9%→48.1%，IFEval 约 3×；作者后续称 Hub 重跑约 51.0%。作者博客 + 高互动原推 + AIHOT 事件页交叉；增益数字来自研究者一方，独立全量复现尚薄，标未证实。

为什么重要

把「改能力」从微调循环挪到直接改权重——若成立，模型修补路径会改写。

要点
  • 动作：Astra 直接改 Qwen3.5-0.8B 权重；无梯度、无训练循环
  • 数字：改 131,072 权重（0.016%）；MATH-500 7.9→48.1；IFEval ~3×（作者数字）
  • 互动：@rikiyatakehi 原推 ~54k likes · AIHOT 热榜第 1；Hub 第三方重跑称 ~51%
  • 交叉：作者博客 + 原推 + AIHOT；独立全量复现仍薄 → 未证实旗
