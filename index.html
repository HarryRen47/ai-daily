A thousand fewer paths to root（来源：openai.com OG）

介绍

北京时间 11-04 16:00（UTC 08:00，窗内），OpenAI 发布 *A thousand fewer paths to root*：即将推出的 cyber 模型驱动发现→验证→利用评估→补丁流水线，在 2026 年 10 月中旬对最新 Linux 内核一次运行中，动态复现 1,724 个漏洞，产出 948 个可工作的本地提权（LPE）利用与对应候选补丁；总 API 成本 $1,213,430，约 $1,279/LPE。另称采样中至少 10 种新型利用技术（咨询外部内核利用专家后仍觉新）。官帖主要在窗后；主线以官网 + AIHOT + Unite.ai 交叉为准。

要点
  • 数字：候选 2,308 → 复现 1,724 → 独立 LPE 948；信息泄露 PoC 291
  • 成本：总 API $1,213,430 · 均 $1,279/LPE；按历史 Pwn2Own/$20k–Typhoon/$70k 假估值约 16×–55× 成本
  • 新颖性：采样利用中至少 10 种新技术（OpenAI + 外部专家口径）

Anthropic FlashProve：zkSNARK 可验证推理，~110 tok/s · ~19MB / 1024 tok

11-04 04:10 北京时间@AnthropicAI 窗内官帖 · ~5.0k 赞 · AIHOT 热榜 #6独立来源 4 家

Progress on provable inference（来源：anthropic.com OG）

介绍

北京时间 11-04 04:10（UTC 11-03 20:10，窗内），@AnthropicAI 官宣 FlashProve：用 zkSNARK 证明「这段回复来自所承诺的模型权重」，不暴露权重。在 Llama 4 Maverick（400B MoE、4-bit）上，单卡 H100 约 110 tokens/s 出证，约 19 MB/1,024-token 请求（相对 vLLM 约 70–95× GPU 时间）。研究页 Published Nov 2（窗前），本窗以官方 X 放大 + Decoder/TC 跟进计入；Apache 2.0 开源 + Lean 形式化。昨日速览「窗外」条目今日升格主线。

为什么重要

要点
  • 性能：单 H100 ~110 tok/s · 证明 ~19 MB/1024 tok · 验证约 17 s/24 线程 CPU
  • 范围：隐藏权重、不隐藏架构；当前上下文上限 1,024；贪婪解码整数模型
  • 开源：代码 + Lean 顶层定理 · Apache 2.0
  • 交叉：anthropic.com + @AnthropicAI + The Decoder（TC 亦有报道）
