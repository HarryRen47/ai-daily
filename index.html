Gemini 4 Carbon 发布封面（图片来源：Google / DeepMind 官博）

介绍

Google DeepMind 宣布向开发者、企业、科学家和普通用户开放 Gemini 4 Carbon，定位为「最强」前沿模型，主打网络安全能力，以及复杂知识工作、软件工程与科学推理中的长程智能体工作流。官博写明：付费开发者与企业可在 Gemini API、Google AI Studio 和 Gemini for business 使用，并正在向所有 Google AI Ultra 订阅者在 Google Antigravity、Gemini 应用和搜索 AI Mode 中推送。入门价与 Gemini 4 Argon 相同，为每百万输入 $2、输出 $10；脚注写明入门期于 2026 年 11 月 30 日结束后，价格改为 $4 / $20（仅适用于面向公众访问的 Carbon 模型）。官方称 Carbon 会比 Argon 消耗更多 token，以做更充分的探索、推理与校验循环；多数日常软件工程与知识工作仍建议用 Argon。

为什么重要

这是当天分量最重的模型开放：把「日常主力」Argon 与「极限任务」Carbon 明确拆开，并在 Antigravity 预览 /swarm，用一个提示调度多智能体团队。需要注意官方时间戳正好卡在北京时间 11 月 11 日 0 点，交叉报道多数出现在窗后。

要点

05安全未证实项

Ars：超 10 万份 Claude Code 本地设置文件出现在公开 GitHub，约 1100 份含机密、涉及 63 个组织

11-10 北京时间Ars 17:24Z · IT之家 16:45 北京，均在窗内独立来源 2 家

Ars Technica 报道配图（图片来源：Ars Technica / Aurich Lawson）

介绍

Ars Technica（2026-11-09T17:24:26Z，北京 11-10 01:24）报道，安全公司 Apiiro 发现超过 10 万份 Claude Code 本地设置文件被上传到公开 GitHub 仓库。Ars 写明：其中约 1,100 份来自 63 个组织，含有 API token、数据库密码或私钥等机密。问题出在用户选择「Yes, and don’t ask again」批准 Shell 命令时，完整命令（可能含密码）被写入项目目录下的 .claude/settings.local.json；该文件通常只被加入开发者全局 .gitignore，并不自动写入仓库级忽略规则，在换机克隆或后补 git init 时可能被提交。Ars 还称，Apiiro 发现 Claude Code 有时会在未经用户确认的情况下自行提交该文件的变更。

为什么重要

这不是远程攻击，而是本地授权记录被意外公开。官方尚未发新闻稿，但 Claude Code 负责人 Boris Cherny 已在 Hacker News 表示团队正在研究预防措施，并建议使用密钥扫描。

要点
  • 已在 Ars 核对的数字：公开仓库中的本地设置文件超过 10 万份；约 1,100 份、来自 63 个组织含有机密；其中 215 份未被 gitleaks 与 TruffleHog 两个常用扫描器标出。即使原仓库删除文件，fork 中仍可能残留。
  • 机制与回应：命令原文（含嵌入的密码、令牌）可能被原样写入设置规则。2025 年 8 月已有相关 bug 报告，后因 60 天无活动被关闭。Cherny 称这些文件「本不应提交到 git」，并提到团队在考虑把密钥扫描做进 Claude Code；另有用户指出 auto mode 仍可能把敏感命令写入设置文件。
  • IT之家另引、本期未在 Apiiro 原文核对的数字：IT之家（北京 11-10 16:45）在转述 Ars 的同时，写到结合 git 历史等共识别 1,994 个代码库中的 2,539 个真实凭据，并点名 Azure 数据库密码、Square 生产令牌、SSH root 登录等案例。Apiiro 官方博文本期抓取为 JS/500，未能打开原文，故 2,539 / 1,994 及「真实凭据」是否经过有效性验证，一律标未证实，不以之作为标题数字。
